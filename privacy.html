Privacy policy

Last updated: October 28, 2026

shorts-bot is a private tool used only by its owner, Isaiah Theo, to operate his own YouTube channel.

What data it accesses

  • With the owner's Google authorization, it reads the owner's YouTube channel information (channel name, ID, public statistics) and the channel's YouTube Analytics reports (for example views and watch time).
  • Only if the owner later grants upload permission, it uploads the owner's own videos to the owner's channel.

It does not access any other person's Google account, and it does not collect personal information from viewers.

How data is used and stored

Data is used only to monitor and operate the owner's channel. Channel statistics are stored in the owner's private code repository. Authorization credentials are stored encrypted (GitHub Actions secrets) and are never published.

Sharing

Data is not sold, shared with third parties, or used for advertising. shorts-bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
